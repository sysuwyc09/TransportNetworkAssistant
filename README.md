# 传输网优化智能诊断工具

> 面向传输网络规划、运维场景，基于 PySide6 开发的桌面端智能分析诊断工具，配套【传输通】AI 智能体知识库沉淀

## 📋 项目简介

**产品名称：传输网优化智能诊断工具**

传输网优化智能诊断工具是面向传输网络规划与日常运维场景、基于 PySide6 自主研发的桌面端智能分析工具。
可导入资源中心导出的机房、设备、光缆、箱体及 PON 端口数据，自动挖掘汇聚机房薄覆盖、上联紧张箱体、零利用率光缆等 **11 类传输短板**，输出优化方案清单，并以可视化界面展示箱体上联拓扑与 OLT 端口面板，支撑分阶段传输补强规划与决策。

## ✨ 核心能力

### （一）资源短板智能诊断

支持导入机房、设备、光缆、箱体及端口资源表格，自动完成字段映射与本地数据库更新；
按汇聚覆盖、箱体上联、端口占用、光缆利用率、ONU 弱光等规则开展多维诊断，自动识别 11 类传输网络短板；
输出短板结果清单，同时生成热力图、汇聚覆盖图层数据，支撑汇聚机房选址、OLT 补密规划。

### （二）优化方案自动输出

基于管线资源构建光缆网逻辑拓扑，对全量箱体完成到各 OLT 机房的上联算路，自动计算路径长度、跳数、光衰，筛选保留距离最短、纤芯最多、路径最优的 Top5 上联方案；

- ONU 弱光 PON 口：输出光模块更换方案
- 超长主光路：输出路由调整、光路割接方案
- 重载 OLT 站点：输出业务均衡分流方案
  最终生成可落地的优化任务清单。

### （三）资源与方案快速查询

依托 PySide6 + QChart 可视化模块：

- 箱体上联拓扑展示（最优评分、最大芯数方案）
- OLT 端口面板可视化、端口占用状态展示
  替代人工跨多表格核对资源，大幅提升传输规划、PON 主光路方案编制效率。

### （四）方案数据知识沉淀

自动分析产出的箱体上联方案集、站点端口数据集，同步作为 **传输通 AI 智能体** 的知识库；
区县网络部、一线网格、网络线其他部门可在智能体广场检索查询上联方案、端口资源数据，实现运维规划经验显性化、方案可复用。

## 🎯 应用场景

1. **传输短板定期诊断**
   规划人员周期导出资源中心机房/设备/光缆/箱体/PON端口数据并导入工具，数十秒完成全量11类短板扫描，输出短板清单与落图图层，支撑汇聚节点新建、OLT补密、光缆扩容等规划决策，替代人工逐表统计。
2. **优化方案编制与落地**
   适配 ONU 弱光专项整治、超长主光路调整、重载 OLT 业务均衡场景，自动输出光模块更换、光路割接、业务分流清单。

> 落地成效：已支撑 1500 个 PON 口光模块更换、350 个超长主光路优化割接、3 个重载机房业务均衡。

3. **资源方案即时查询**
   一线运维、网格人员通过图形界面快速查看箱体上联拓扑、OLT 端口占用状态，无需翻阅大量原始资源表。

## 📂 数据说明

- 输入数据源：资源中心导出标准化表格（机房、设备、光缆、箱体、PON端口）
- 自动处理：字段映射、数据清洗、入库、拓扑构建、诊断计算
- 输出产物：短板清单Excel、优化方案清单Excel、可视化图层、拓扑图、OLT面板视图

> ⚠️ 注意：导入文件需要按照工具内置模板字段规范，字段不一致会导致映射失败。

## ⚠️ 使用注意事项

1. 本工具为内部传输网运维规划桌面工具，**仅限内部生产资源分析使用，禁止外传原始资源数据**；
2. 地理图层、地图相关展示依赖 geopandas，首次运行若报错请检查 GDAL / fiona 安装；
3. 大数据量导入（万级箱体、光缆）建议关闭其他占用内存软件；
4. 知识库同步模块依赖【传输通】AI智能体接口，离线环境仅支持本地诊断与方案查看。
